Tally — design brainstorm // low-fi wireframes · explore the design space, then pick

starting point

Tally already has the bones: leaderboard, library, players/shops, sessions. After staring at it for a bit, I see four threads worth pulling: (1) the home page is a wall of stats with no obvious next action, (2) sessions exist but you can't browse or relive them, (3) the library cards are mostly empty rectangles, and (4) the app could be way more fun — it's a board-game tracker, lean into rivalry, streaks, "what should we play tonight?"

Below: observations, then 3 home concepts, then new surfaces (sessions feed, game-night planner, game detail, player profile), then library card variants, then IA tweaks.

01 what I noticed

1

Home is read-only

Big leaderboard + 3 tables. No "Log a session", no "Play tonight" CTA. The primary verb of the app is missing from the front door.

2

Sessions vanish after logging

You record a session, it updates stats, then disappears. No timeline / history view to scroll back through "remember when…"

3

Library cards are empty ★ priority

Tall cards with a small dice icon and a name. Cover art slot, owner badge, last-played, player count would all earn their place.

4

Players + Shops bundled awkwardly

A pill-toggle hides shops behind people. Shops are a different noun (where you rent from) — they want their own surface or to be reframed.

5

No game detail / player profile (visible)

Where do "Marina's stats" live? Where do I see all sessions of Rumikubi? Big opportunity for delight + drama.

6

"What should we play?" is the real question

Given who's here tonight and how long we have, surface the right game from the library. This is the killer feature hiding in plain sight.

06 mobile

Mobile is where this app lives — board games happen on tables, phones are in pockets. The desktop sidebar collapses to a bottom tab bar, the leaderboard podium becomes a horizontal scroller, and the primary verb (+ Log) gets a floating action button that's always reachable with a thumb.

player profile · drilldown
Bottom tab bar (4 items): Home / Library / Plays / Crew. Settings tucks behind a profile avatar in the home top-right.
Persistent FAB for + Log. Always one thumb-tap from logging. Opens as a bottom sheet, not a route change.
Podium goes horizontal: swap the 3-column trophy graphic for a horizontally-scrolling carousel of all players, not just top 3.
Tables → cards: the Win Rate / Sessions / Most Played tables don't fit. Each row becomes a stacked card with label/value pairs.
Filters: chips above the list, not inline. Multi-select dropdowns become full-screen filter sheets.
Touch targets ≥ 44px. Edit/Delete on player rows currently look ~28px — bump up, or make the whole row tap-to-edit with swipe-to-delete.

07 small wins (low effort)

Make the global + Log session button persistent in the topbar — single biggest UX lift.
Empty library cards: drop in a BGG cover art import using the existing dataset.
On Players list, group by Active / Inactive (no sessions in 90d) instead of alpha.
Add session notes / photo field — turns a stats tracker into a memory keeper.
Settings → scoring rules (3-2-1, 5-3-1, custom) so leaderboard math matches your group.
Currency is set but unused — wire it into a "games owned" library value stat or remove.
